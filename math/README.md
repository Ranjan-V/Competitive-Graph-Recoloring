# Mathematical Core

This folder contains the rigorous mathematical core for the competitive graph
recoloring letter.

- `main.tex` is a standalone compilable LaTeX file.
- `sections/core_recoloring_result.tex` is the paper-ready snippet containing
  the notation, Lemma 1, Theorem 1, and the empirical-scaling remark.

Compile from this folder with:

```powershell
pdflatex main.tex
```
