# Final Paper Draft

This folder contains the Applied Mathematics Letters manuscript draft using the
`elsarticle` files from `correct template/`.

- `main.tex`: final paper source.
- `main.pdf`: compiled manuscript.
- `figures/steps_vs_edges.png`: copied figure from the full experiment.
- `data/scaling_results.csv`: copied CSV data from the full experiment.
- `elsarticle.cls`: generated from `correct template/elsarticle/elsarticle.ins`.
- `elsarticle-num.bst`: copied from the correct template bundle.
- `correct template/`: source Elsevier template bundle.

Compile from this folder with:

```powershell
..\math\tools\tectonic.exe main.tex
```

The author names, emails, and affiliation have been filled in the manuscript
source.
